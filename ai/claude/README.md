## Requirement (paid Claude)

Listing connectors in Anthropic’s directory typically needs a **paid Claude** plan or approved org workspace. Confirm current rules on [https://claude.ai](https://claude.ai) before submitting.

## Endpoint

- **MCP (streamable HTTP):** `https://api.pandlens.com/mcp`
- **Header:** `X-Api-Key` (the user’s Pandlens API key)
